## Cakupan data dummy dan alur

Data ditandai `QA-DUMMY-*` dan hanya ditulis ke database SIPATUH lokal. Set terakhir yang lolos: `QA-DUMMY-1793802161116`. Data database dan file unggahan tidak disertakan dalam Git; skrip pengujian dapat membuatnya kembali.

| Modul | Pemeriksaan |
| --- | --- |
| Master data | Buat/ubah jenis pemeriksaan dan status; buat/nonaktifkan template dummy terpisah |
| Pengguna | Baca/ubah pengguna dummy nonaktif; validasi aktivasi tanpa Irban; penolakan akses Bupati |
| Unit kerja/Irban | Daftar SIMPEG dan mapping; pemilihan unit setiap Irban; buat mapping bila belum tersedia |

| LHP | Buat/ubah, nomor duplikat, upload/download PDF, tutup/buka kembali, penolakan mutasi setelah ditutup |
| Temuan/rekomendasi | Buat/ubah/baca/hapus record dummy |
| Tindak lanjut | Lampiran PDF, histori bertambah tanpa menimpa, ringkasan finansial, pelunasan tidak otomatis mengubah status |
| Verifikasi | Keputusan manual, catatan wajib, status diperbarui, file ditolak tanpa menyimpan verifikasi |
| Surat peringatan | Evaluasi jatuh tempo, urutan SP1–SP3, buat/ubah/regenerasi/download draft PDF |
| Laporan | Ringkasan, ekspor CSV dan PDF |
| Dashboard | Ringkasan Pimpinan dan Irban dengan data terisi |
| Otorisasi | Akses lintas Irban ditolak, Bupati tidak boleh menulis, request tanpa token ditolak |

## Perbaikan

1. JWT `sub` dipetakan menjadi `id` untuk layanan bisnis; memperbaiki pencatatan pelaku, tindak lanjut, dan verifikasi.
2. Lima foreign key lokal yang masih menunjuk tabel lama `User` diperbaiki menjadi `UserAccess`. Tidak ada data yatim atau data yang dihapus. SQL perbaikan disertakan sebagai migration terpisah; telah diterapkan pada database lokal.
3. Penutupan LHP ditolak jika masih ada rekomendasi belum selesai, sesuai panduan pengguna.
4. Validasi seluruh lampiran dilakukan sebelum membuat LHP/tindak lanjut atau menyimpan keputusan verifikasi, sehingga file tidak valid tidak meninggalkan record parsial.

## Menjalankan ulang

Dari direktori `backend`, dengan backend lokal sudah berjalan:

```sh
node scripts/qa-local.cjs          # Pemeriksaan baca saja
node scripts/qa-local.cjs --write  # Membuat satu set dummy baru dan menjalankan alur lengkap
```

Skrip menolak database nonlokal dan lingkungan production. Token QA dibuat sementara dari konfigurasi lokal, tidak dicetak atau disimpan. Identitas EGOV/SIMPEG tidak diubah. Pengguna dummy tetap nonaktif.
